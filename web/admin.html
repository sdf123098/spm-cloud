    正版与第三方游戏身份

    模组与网页共享已验证的游戏身份。若该游戏身份已经属于你的另一个 Cloud 账号，验证成功后可自动建立账号关联。

    手动验证绑定

    也可以在模组中登录上述 Cloud 账号并绑定当前游戏身份，再点击“刷新绑定”。手动令牌验证仍会联系身份服务校验，不能只填写名称或 UUID 冒认。
